# /images/testimonials/

Headshot images used by the customer-review carousel at the bottom of 04 購皂.

## Filename contract

```
<id>.jpg     ← primary source
<id>.webp    ← auto-generated by npm run optimize:images
<id>.avif    ← auto-generated by npm run optimize:images
```

`<id>` is the `id` field in [src/data/testimonials.js](../../../src/data/testimonials.js).
Currently 8 IDs: `lin`, `chen`, `wang`, `li`, `mandy`, `huang`, `tina`, `chou`.

## Spec

| Field | Value |
|---|---|
| Aspect ratio | **1 : 1 square** |
| Min resolution | 800 × 800 |
| Recommended | 1000–1200 px square |
| Format | jpg input → optimize:images produces avif + webp |
| Subject | East-Asian individual, editorial headshot or candid bathing-routine vignette |
| Mood | Calm, soft natural light, low-contrast Japanese minimalism feel |
| Treatment | Light film grain OK; no heavy filters; no logos / watermarks |

The carousel crops to a circle with `border-radius: 50%`, so keep the face
roughly centred with comfortable margin on all four sides.

## Generation pipeline

See [PROMPTS.md](./PROMPTS.md) for 8 ready-to-paste Nanobanana / Gemini
prompts (one per `id`).

```bash
# Same pipeline used for journal/ covers and product real-photo refresh
node scripts/generate-images.js --tasks scripts/tasks/testimonial-headshot-tasks.json
npm run optimize:images
```
